# 🏨 HostelAssist

**HostelAssist** is a complaint management system designed for hostel residents and administrators. It allows students to log complaints and admins to track and resolve them efficiently.

---

## 🚀 Features
- 🏠 **Student Portal**: Submit complaints with room details.
- 🛠 **Admin Portal**: View, manage, and resolve complaints.
- 🔒 **Authentication**: Secure login for students and admins.
- 📩 **OTP Verification**: Admins verify complaints via OTP.
- 📊 **Complaint Tracking**: Track complaints based on status.
- 📡 **MERN Stack**: Full-stack web application using **MongoDB, Express.js, React, and Node.js**.
